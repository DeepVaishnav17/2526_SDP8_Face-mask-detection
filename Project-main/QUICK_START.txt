📊 FEATURES OVERVIEW

✓ Person Entry Tracking
  - Virtual entry zone (yellow line)
  - Unique ID for each person
  - Prevents duplicate logging

✓ Automatic Snapshot
  - Photo captured on entry
  - Saved with timestamp & ID
  - Location: entry_snapshots/

✓ Entry Logging
  - CSV file: entry_log.csv
  - Fields: Timestamp, ID, Status, Confidence
  - Downloadable from dashboard

✓ Live Dashboard
  - Real-time statistics
  - Recent 10 entries
  - Visual alerts for no-mask

📋 HOW IT WORKS

1. Camera detects person → Assigns ID (e.g., Person #1)
2. Person approaches → Tracked on screen
3. Crosses yellow line → Entry logged!
4. Snapshot captured → Saved to folder
5. CSV updated → Entry record created
6. Dashboard updates → Statistics refreshed
